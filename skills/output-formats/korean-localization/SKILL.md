# 한국어 지원 (Korean Localization)

이 스킬은 독립적인 분석 스킬이 아니라, 다른 스킬의 결과물을 한국어 사용자에게 맞게 다듬는 출력 레이어다. 분석 로직은 상위 스킬을 그대로 따르고, 언어·단위·용어·데이터 소스만 조정한다.

## 적용 조건

- 사용자가 한국어로 질문한 경우, 별도 요청이 없어도 최종 답변을 한국어로 작성한다.
- 사용자가 영어로 질문했더라도 한국어 출력을 명시적으로 요청하면 한국어로 작성한다.
- 한국 상장사, 원화 표시 자산, 한국 거시지표를 다룰 때는 출력 언어와 무관하게 아래 단위·데이터 소스 규칙을 참고한다.
- 상위 스킬의 출력 계약(output contract)이 정한 블록 순서와 형식 제한(예: 마크다운 금지, 표 금지)은 그대로 지킨다. 이 스킬은 언어만 바꾼다.

## 워크플로우

### 1. 출력 언어 결정

- 사용자 메시지의 언어를 기준으로 한다. 섞여 있으면 마지막 요청의 주된 언어를 따른다.
- 한국어 출력이 결정되면 제목, 소제목, 본문, 차트 제목, 축 라벨, 주석, 면책 문구까지 모두 한국어로 쓴다.

### 2. 용어 표준화

- `references/korean-finance-glossary.md`의 표준 용어를 사용한다.
- 핵심 개념은 처음 등장할 때 한국어 뒤에 영문을 괄호로 병기한다. 예: 잉여현금흐름(FCF), 가중평균자본비용(WACC).
- 이후에는 한국어 또는 널리 쓰이는 약어 중 하나로 일관되게 쓴다.
- DCF, EBITDA, ROIC, EV/EBITDA, P/E처럼 한국 시장에서도 약어로 통용되는 지표는 번역하지 않는다.
- 데이터 태그 등 기계가 읽는 마커는 상위 스킬이 정한 원문 그대로 유지한다.

### 3. 숫자·단위·날짜 형식

- 원화 금액은 억·조 단위로 표기한다. 예: 1,234,500,000,000원 → 1조 2,345억 원.
- 외화 금액은 원 통화를 유지하고 필요하면 원화 환산치를 병기하며, 적용 환율과 기준일을 밝힌다. 예: 120억 달러(약 16.5조 원, 1,375원/달러, 2026-10-14 기준).
- 퍼센트와 퍼센트포인트를 구분한다. 예: 금리 0.25%p 인상.
- 날짜는 `YYYY-MM-DD` 또는 `YYYY년 M월 D일`로 쓰고 한 문서 안에서 섞지 않는다.
- 회계연도는 `FY2025` 또는 `2025년` 중 하나로 통일하고, 분기는 `2025년 3분기(3Q25)`처럼 쓴다.
- 한국 기업은 연결 기준과 별도 기준을 반드시 구분해 밝힌다.

### 4. 한국 시장 데이터 소스

- 공시·재무제표: 금융감독원 DART(전자공시시스템)
- 시세·거래 데이터: 한국거래소(KRX) 정보데이터시스템
- 거시지표·금리·환율: 한국은행 경제통계시스템(ECOS)
- `openbb-data-fetcher` 등 해외 데이터 도구에서 한국 종목을 조회할 때는 Yahoo Finance 형식 티커를 쓴다. 유가증권시장(KOSPI)은 `005930.KS`, 코스닥(KOSDAQ)은 `035720.KQ`처럼 6자리 종목코드 뒤에 접미사를 붙인다.
- 해외 데이터 소스와 국내 공시 수치가 다르면 DART 원문을 우선하고 차이를 명시한다.

### 5. 문체

- 리서치 보고서 문체(서술형 "~이다", "~로 판단한다")를 기본으로 한다. 사용자가 대화체를 원하면 "~입니다" 체를 쓴다.
- 번역투를 피한다. 예: "~하는 것이 가능하다" 대신 "~할 수 있다".
- 투자 판단 표현은 국내 증권사 관행을 따른다: 매수(Buy), 보유(Hold), 매도(Sell), 목표주가, 상승여력.
- 면책 문구는 한국어로 작성한다. 예: "본 자료는 투자 판단의 참고용이며, 투자 결과에 대한 책임은 투자자 본인에게 있다."

## 품질 점검

- 영어 문장이 번역되지 않은 채 남아 있지 않은가
- 같은 개념을 서로 다른 한국어 용어로 섞어 쓰지 않았는가
- 원화 단위와 기준일, 환율이 명확한가
- 상위 스킬의 형식 제한을 어기지 않았는가
