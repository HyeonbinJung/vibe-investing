# 펀더멘털 분석 최상위 가이드

## 적용 범위

- 하위 경로의 파일이 별도로 재정의하지 않는 한, 이 규칙을 `skills/fundamental-analysis/` 및 그 하위 항목 전체에 적용한다.

## 목적

- 바텀업(bottom-up) 밸류에이션 및 펀더멘털 분석 스킬을 얕은 폴더 구조로 보관한다.

## 구조

- 스킬 폴더는 `skills/fundamental-analysis/` 바로 아래에 평평한 구조로 두는 것을 우선한다.
- 스킬 이름의 예로는 `company-analysis`, `crypto-analysis`, `credit-analysis`, `special-situations` 등이 있다.
- 평평한 구조가 명백히 한계에 부딪히지 않는 한 중간 폴더를 추가하지 않는다.

## 규칙

- 공통 프레임워크 로직은 각 스킬의 `SKILL.md`와 `references/`에 둔다.
- 폴더 깊이를 늘리는 것보다 깔끔하다면, 자산별 변형은 스킬 번들 내부에 둔다.
- 상장기업 워크플로는 해당되는 경우 기대치 우선(expectations-first), 역DCF(Reverse DCF) 우선 원칙을 유지한다.
